Object Manipulation

The game

  • You will be presented with a rotatable object in a room

Controls

  • ← → : rotate the object using the arrow keys
  • ␣ : press the spacebar (or tap the screen) to interact with the object

General rules

  • The textures take a moment to download. After that, a countdown from 3 starts before the game begins
  • Do not exit fullscreen during the game
  • Play on your main monitor — not on an external / attached display
  • Close all other apps and browser tabs
  • The session lasts at most 20 minutes (it may end sooner)
  • Between levels the screen goes black and a clock at the top shows the time left in the session
  • Your data is saved automatically after every trial

Hint: pay attention to the object's details
