LOG + PLOT REFERENCE
====================

Generated by controller_python/controller.py (native) and controller_main.js (web).
Analyzed by tools/verify_trial_logs.py.


─── LOG FILES ───────────────────────────────────────────────────────────────

trial JSON
  path : <session>/level_xxx/HHMMSS/trials/<participant>_level_xxx_trial_xxx_run_xxxx_object_xxx_<stamp>.json
  one per trial. Schema:

    level_index            int          which level
    active_chain           int          which object/chain inside the level
    trial_index_in_chain   int          0-based index into trials[] for this chain
    trial_run_counter      int          monotonically increasing across the session
    trial_config           dict         flat trial config (object + per-trial overrides)
    start_orient           float        radians, actual random pick (NOT the editor sentinel)
    outcome                str          "advance" | "stay" | "retroceed"
    nr_attempts            int          number of check-presses in the trial
    elapsed_time_no_anim   float        seconds spent NOT in animation (sub-frame precise)
    elapsed_time_anim      float        seconds spent IN animation
    timestamp_start        ISO str
    timestamp_end          ISO str
    session_info           dict         platform / refresh_rate / app_start_unix_ns
    win_event              dict | null  { win_elapsed_secs:float, win_frame_number:int,
                                          present_elapsed_secs:float }
    frames                 dict[str → { state_read:dict, commands_sent:dict }]
                                        keyed by trial-relative frame_number ("0", "1", ...)

  per-frame state_read (subset of LOGGED_STATE_FIELDS):
    frame_number             int    trial-relative, starts at 0
    render_frame_number      int    trial-relative, starts at 0
    present_elapsed_secs     float  wall-clock since app start (monotonic, app-wide)
    photodiode_white         bool
    camera_radius/x/y/z      float
    attempts                 int    cumulative checks so far
    current_alignment        float  cos(angle to target)
    current_angle            float  radians
    is_animating             bool
    is_blank                 bool
    is_rendering_stopped     bool

  per-frame commands_sent (controller → game):
    rotate_left/right        bool
    zoom_in/out              bool
    check                    bool
    reset                    bool
    toggle_blank             bool
    toggle_stop_rendering    bool
    animation_door           bool
    animation_all_door       bool
    animation_colored        bool


level summary JSON
  path : <session>/level_xxx/HHMMSS/<participant>_level_xxx_summary_<stamp>.json
  one per level-run. Schema:

    participant             str
    level_index             int
    level_name              str          "level_xxx"
    level_run_counter       int
    session_info            dict
    level_config            dict         level dict WITHOUT "fixed" block
    timestamp_start/end     ISO str
    elapsed_time_no_anim    float        sum across trials_runs
    elapsed_time_anim       float        sum across trials_runs
    level_completed         str          "completed" | "interrupted"
    trials_runs             list[dict]   one per trial; each contains:
        trial_index_in_chain, active_chain, trial_run_counter,
        outcome, nr_attempts,
        elapsed_time_no_anim, elapsed_time_anim,
        start_orient, win_event, file (trial JSON basename)
    timing_health           dict         { present_dt_mean_ms, present_dt_std_ms,
                                            render_gaps, freeze_events, drift_max_s }
    prev_file / next_file   str | null   linked list of level runs


─── PLOT FILES (tools/verify_trial_logs.py) ─────────────────────────────────

out/analysis/<platform>/<session>/<level_xxx>/<trial_file>.png
  per-trial. 2 rows × 3 cols:
    [0,0]  Camera angle trajectory     (x = present_elapsed_secs)
    [0,1]  Instantaneous FPS timeline  (x = present_elapsed_secs)
    [0,2]  Presentation Δt histogram   (mean, ideal, 1% low, 0.1% low; outlier %)
    [1,0]  Commands raster, 60 Hz-snapped (one tick per channel: rotate_left/right,
                                            check, reset, toggle_blank/stop,
                                            animation_door)
    [1,1]  Drift timeline              ((present - t0) - row_count/60; anim included)
    [1,2]  Present Δt timeline         (x = present_elapsed_secs, render-gap markers)
  cols 0 and 1 share x within each column.

out/analysis/<platform>/<session>/<level_xxx>/session_overview.png
  one per level-run. 5 stacked panels sharing x = cumulative elapsed time (s).
  Trials drawn as elapsed-time-proportional slots, separated by thin gray dashed
  vertical lines.
    1) Outcome strip
    2) Attempts CDF (cumulative attempt count, step plot)
    3) Activity strip — blue = active, green = animating
    4) Alignment trajectory with attempt dots + animation shading
    5) Per-frame Δt timeline (ms)
  Title: "level_xxx — N trials  (no_anim, anim, total)"
  Bottom x-tick labels: level_xxx_trial_xxx_run_xxxx_object_xxx

out/analysis/<platform>/<session>/session_overview.png
  cross-level: same 5 panels, ALL trials end-to-end with bold black vertical
  delimiters between trials of different levels.
  Title: "all levels — N trials  (no_anim, anim, total)"

out/analysis/<platform>/<session>/summary.txt
  per-trial table + per-platform aggregate (frames, gaps, dups, freezes,
  Δt mean/σ/min/max, FPS, 1%/0.1% low FPS, outlier%, drift) plus a
  cross-platform comparison if both native and wasm are loaded.
